CURRENT PORT-SELECTION LOGIC
----------------------------

1) scripts/update_catalog.py

ALLOWED_PORTS = {80, 443}

Normal VLESS / VMess / Trojan / Shadowsocks parsing is filtered by:

    host, port, remark, _ = endpoint_from_uri(uri)
    if not host or port not in ALLOWED_PORTS:
        continue
    rows.append({"uri": uri, "protocol": protocol, "host": host, "port": port, "remark": remark, "country": "UNKNOWN", "source": source_name})

OpenVPN remote endpoints are filtered by the same ALLOWED_PORTS set:

    remotes = re.findall(r"^\\s*remote\\s+(\\S+)\\s+(\\d+)\\b", config, flags=re.MULTILINE)
    allowed = [(host, int(port)) for host, port in remotes if int(port) in ALLOWED_PORTS]
    if not allowed:
        continue
    host, port = allowed[0]

2) scripts/build_tcp_pool.py

The generated metadata records the selected ports in both app_pool.json and tcp_reachable.json:

    "allowed_ports": [80, 443],

3) .github/workflows/update.yml

The workflow explicitly verifies that generated app-pool metadata still reports only ports 80 and 443:

    if data.get('allowed_ports') != [80, 443]:
        raise SystemExit(f"unexpected allowed ports: {data.get('allowed_ports')}")
