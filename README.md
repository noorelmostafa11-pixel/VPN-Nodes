# Ahmed VPN Nodes

Automated aggregator for publicly available V2Ray/Xray node feeds used by Ahmed Personal VPN.

## What it does

- Fetches public upstream sources on a schedule using GitHub Actions.
- Supports VLESS, VMess, Trojan and Shadowsocks.
- Accepts only endpoint ports **80** and **443**.
- Resolves country from country-specific feed, URL/filename metadata, node remark, and only then source metadata.
- Rehomes a node when its explicit metadata points to another country instead of deleting it.
- Keeps unclassified nodes in `UNKNOWN`.
- Deduplicates nodes by normalized endpoint identity.
- Performs bounded TCP reachability checks before publishing.
- Publishes country and protocol feeds plus machine-readable metadata.

## Design

The repository is the heavy aggregation layer. Android should consume the generated feeds rather than scraping all upstream repositories directly.

```text
Upstreams -> fetch -> decode -> parse -> country resolve -> dedup -> port filter -> health check -> publish
```

## Upstream sources

The initial upstream set is intentionally limited to maintained/public repositories:

- https://github.com/rtwo2/FastNodes
- https://github.com/Baarcuda/vpn-configs
- https://github.com/Alirewa/V2ray-Configs
- https://github.com/0xRadikal/Free-v2ray-Configs
- https://github.com/Epodonios/v2ray-configs
- https://github.com/zengfr/free-vpn-subscribe
- https://github.com/sakha1370/OpenRay
- https://github.com/Au1rxx/free-vpn-subscriptions
- https://github.com/SoliSpirit/v2ray-configs

Upstream projects retain their own licenses and attribution. This repository is an aggregator; it does not claim ownership of upstream configuration data.

## Outputs

- `output/countries/<ISO>.txt`
- `output/countries/UNKNOWN.txt`
- `output/protocols/vless.txt`
- `output/protocols/vmess.txt`
- `output/protocols/trojan.txt`
- `output/protocols/ss.txt`
- `output/metadata/index.json`
- `output/metadata/countries.json`
- `output/metadata/health.json`

Files are deliberately generated by CI and should not contain source secrets.
