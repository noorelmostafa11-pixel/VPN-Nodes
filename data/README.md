# Offline GeoIP database

The catalog builder uses `data/GeoLite2-Country.mmdb` locally for country classification. No GeoIP web API is called during node classification.

The database is maintained by `.github/workflows/update_geolite2.yml` and is refreshed monthly (and manually on demand).

Required GitHub Actions secrets:
- `MAXMIND_ACCOUNT_ID`
- `MAXMIND_LICENSE_KEY`

The binary database is not generated by the catalog workflow itself. Run the GeoLite2 update workflow once to seed or refresh the local MMDB before running the catalog workflow.
